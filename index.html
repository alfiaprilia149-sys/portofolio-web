Rooted in logic, dibangun dengan rapi

Saya siswa Rekayasa Perangkat Lunak di SMK Telkom Malang yang tertarik menjadi Junior Web Developer di sisi back-end. Saya senang membangun logika server, merancang struktur database, serta mengembangkan REST API untuk aplikasi web — termasuk menerapkan autentikasi menggunakan JWT.

DesserTopia, KostHunter, dan BackLibrary dibangun dengan pola arsitektur yang sama: NestJS (TypeScript) untuk struktur server, Prisma sebagai ORM untuk koneksi database, dan REST API sebagai penghubung antara data dan aplikasi. KitchenLab lahir dari kerja tim yang membutuhkan komunikasi dan problem solving yang baik.
