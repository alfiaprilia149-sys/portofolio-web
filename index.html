Tentang saya

Saya siswa Rekayasa Perangkat Lunak di SMK Telkom Malang (2024–2027) dengan minat pada bidang Junior Web Developer (Back-End). Saya senang membangun logika server, merancang database, dan mengembangkan REST API untuk aplikasi web — termasuk menerapkan autentikasi menggunakan JWT (JSON Web Token).
